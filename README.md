# UAV Ground School Projects

Computer vision homework for UAVs@Berkeley.

| Week | Project | Work completed |
|---|---|---|
| [Week 2](week2/README.md) | Image stitching | Combined video frames into a mosaic and compared alignment and seam-selection methods. |
| [Week 3](week3/README.md) | YOLOv8 object detection | Compared training duration and resizing, then evaluated the selected model on held-out football images. |

Each folder contains its own instructions, code, dependencies, and results. For Week 2, run commands from `week2/`. Week 3 uses a Google Colab notebook.
